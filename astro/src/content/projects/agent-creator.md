Agent Creating Agent is an innovative AI project that automates the creation of new, specialized AI agents. Leveraging the Autogen Core and AgentChat frameworks, it features a creator agent capable of generating, customizing, and deploying new AI agents with unique personalities, goals, and behaviors—all based on a template.

## Key features

- AI agent that writes Python code to create new AI agents, each with distinct system messages and business verticals
- Supports dynamic, on-the-fly agent generation and registration
- Agents can collaborate, refine each other’s ideas, and interact autonomously
- Modular design for easy extension and experimentation

## How it works

The creator agent receives a template and instructions, then generates new agent code with a unique focus or personality. These agents are registered in the system and can interact, brainstorm, and refine ideas together, simulating a dynamic ecosystem of AI collaborators.
