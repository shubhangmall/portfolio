Created formal testing processes and test plans for a Python Flask web application, executing unit testing on Flask routes, integration testing for AWS services connectivity, and load testing to validate Elastic Beanstalk auto-scaling performance using Python testing libraries.

Developed front-end login/signup forms using Flask templates with HTML/CSS/JavaScript, implemented backend API endpoints in Python Flask, and integrated AWS S3 for file storage with PostgreSQL database connectivity for user data management.

Utilized AWS Elastic Beanstalk for application deployment and scaling, managed version control with Git, followed Agile methodology with Jira for project tracking, and presented the deployed Flask application to investors, securing a $2000 grant prize.
