StockPicker is an AI-powered project that automates stock selection using a collaborative team of specialized agents built on the crewAI framework. It identifies trending companies in the news and markets, performs in-depth financial research, and selects the most promising stock based on comprehensive analysis and predefined criteria.

The system is highly configurable—users can define custom agents, tasks, and decision logic. It features persistent long-term and short-term memory for context-aware reasoning and can be extended or integrated with custom tools. Each run produces a clear, actionable investment decision report.

## Key features

- Automated, multi-agent research and decision-making
- Modular and customizable agent/task configuration
- Persistent memory for improved context and learning
- Outputs a ready-to-use investment decision report
